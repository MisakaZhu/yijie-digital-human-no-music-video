# 从作品库直接选取数字人口播原片

用于标准流程第 7–9 步。默认原片留在平台，直接选入剪辑高手；最终成片仍按用户要求下载。不要为了媒体探测或流程惯例先下载一份原片。

## 已观察到的入口

兼容工作台的典型入口（以使用者当前界面为准）：

`剪辑高手 -> 智能包装 -> 上传视频 / 点击上传 -> 上传文件弹窗 -> 作品库 -> 视频`

该弹窗同时有 `手动上传`、`素材库`、`作品库`。作品库提供 `我的 / 部门 / 企业`、搜索、分页和复选框，并列显示 `来自：数字人视频` 与 `智能包装合成结果 / 来自：智能包装原子能力`。用实际当前界面定位；不要固定节点编号、卡片序号、截图坐标或样例文件名。

这是选入源片的入口；底部 `保存到：我的/作品库` 是输出保存位置，右侧 `历史记录` 是输出候选，都不能代替选入原片。

## 1. 离开生成页前保留来源

记录在本次 `CHECKPOINT_PATH` 的 `source_asset` 中：

- 当前数字人生成结果在 UI 暴露的 URL/作品 ID（可用才记，不读取隐藏应用状态）。
- 生成开始/完成时间及页面原始时区，实际播放器时长，开头和另一句有辨识度的已接受口播。
- 作品名、保存位置等可见信息；未知为 `null`。此时标题可能尚未生成，作品也可能叫 `未命名_...`，不能要求名称必须等于后来生成的标题。
- 与本次原始 `source_url` 或直接文案的对应；原片与包装成片的 ID/URL 分开保存。

## 2. 在本次标签里选一条源片

1. 打开 `上传文件`，选择 **作品库**，按实际保存位置查看 `我的` 或相应目录，筛选 **视频**。等待列表加载，别把加载时“暂无内容”立刻判成作品不存在。
2. 用生成时间、可见名称/ID/URL缩小范围；优先 `来自：数字人视频`。包装成片、其他任务原片以及人物相同的旧片不能混入。关键词搜索和翻页只围绕本次记录，不全库逐条点开。
3. 确认身份需要可靠关联：与生成页记录完全对应的源片 URL/作品 ID，或匹配的可辨识口播内容；再用时间、时长等核对。相同人物、未命名、最近时间、最新排序或复选框选中，都不能单独证明是本次。
4. 如果弹窗能预览，先核对。若只能勾选，可将已按本次时间等缩小到的候选 **暂时**载入当前编辑器，先不提交；在左侧源片播放器核对后才认定。来源不明时不能为了前进随便选第一条。
5. 勾选恰好一条，点击本弹窗 `确定`。读取最新状态，确认弹窗关闭、左侧源片载入，并核对源片身份及实际时长。中间成片预览可能仍是旧输出，不能用它判断选入结果。
6. 如果载入了错误候选，只从本次编辑器取消该选择，再回选片弹窗核对其他有根据的候选；不删除库中作品、不重生成、不修改其共享名称。仍无法确认时保留“源片身份待确认”。
7. 成功后记录 `source_transfer = work_library`、选中作品依据和时长，保持 `source_file = null`。直接进入模板设置，不做本地备份、重复上传或要求用户手动下载。

播放只有画面/进度可核对时，按实际能力记录，不能声称已听过音轨。时长从 UI/受支持的媒体信息读取；粗粒度 `2:02` 与精确秒数允许显示取整差异。

## 3. 云端选片的有限恢复与本地备用

- 列表暂时未加载：在当前弹窗等待，必要时重新打开该弹窗一次；不刷新正在工作的整页。
- 列表未出现本次作品：按记录核对保存位置、视频筛选、生成时间和相邻分页。若用户指明库中位置，优先使用该线索。
- 作品已确认但无法载入，或当前界面确实不提供作品库：记录实际限制。仍能从本次生成页通过正常 UI 取得 **已确认原片** 时，可用已授权的下载再上传作为备用，并简短说明原因。
- 无法确认是哪条原片时，本地下载也不能解决身份问题；不要下载别条作品、用最新本地文件顶替或再生成。说明缺少的来源依据。
- 若用户明确禁止下载原片，备用本地传递不可用；保留已生成的云端作品并报告具体阻碍。
- 用户本来就提供本地 MP4 时可直接用该文件，不强行先上传作品库。

本地备用仅下载一次到用户目录，使用 `digital-human-source-{RUN_ID}.mp4` 或记录平台实际文件名，核对真实路径/大小/来源。然后在同一上传弹窗的 `手动上传` 中，用绑定本次标签的文件选择器选择该确切文件，点击 `确定` 并核对左侧源片。不要操作其他任务的系统文件框，不自动删除原文件，也不把备用传递变为日常必选步骤。
