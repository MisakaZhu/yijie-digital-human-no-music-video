# 数字人无音乐视频（公开分发版）

本 skill 操作使用者自己的兼容工作台。安装不会启动生成；任务授权来自当前使用者。本包不含作者的后台地址、账号、声音配置、历史素材或个人预授权。

## 开始与路由

1. 先读 [configuration.md](references/configuration.md)，解析本次 `WORKBENCH_URL`、`DOWNLOAD_DIR`、`RUN_ROOT`、`INDEX_PATH`、声音与形象。缺少任务输入时取得 `SOURCE_URL` 或 `COPY`；分享链接不替代后台地址。
2. 开始网页操作前读 [task-isolation.md](references/task-isolation.md)，为每条视频创建独立 UUID、运行目录和 checkpoint。续做只读取当前对话明确记录的 checkpoint 和绑定标签。
3. 按 [workflow.md](references/workflow.md) 的阶段执行。提取、改写、声音、标题与包装都绑定本次记录；等待或重连后读取最新页面再操作。
4. 新来源生成前读 [recent-sources.md](references/recent-sources.md)，运行自带查重脚本。批次逐条执行，重复项自动跳过；单条重复也不付费重做，除非使用者明确要求重做该来源。
5. 文案质量见 [copy-quality.md](references/copy-quality.md)。本包已有检查标准，不要求另装优化 skill。
6. 数字人原片生成后，按 [work-library-source.md](references/work-library-source.md) 优先用作品库选入包装；不强制下载/重传原片。
7. 包装提交与结果恢复读 [smart-packaging-preview-download.md](references/smart-packaging-preview-download.md)。备用下载只在实际下载授权范围内按 [authorized-local-download.md](references/authorized-local-download.md) 执行。

## 决策与约束

- 使用当前环境公开支持的浏览器 UI 工具。后台 API、隐藏应用状态、猜测 URL/作品 ID 均不是恢复路径。不能操作其他任务的标签或不明归属的系统文件框。
- 工作台入口通常为 `生产部门 → 爆款大师 → 一键追爆`；最终包装用 `剪辑高手 → 智能包装`，跳过一键追爆内嵌智能剪辑。不点击 `AI自动一键生成&发布`。
- 从分享文案中本地提取真实 HTTP(S) 链接后直接回填工作台。例行提取不需要先看原视频、解析短链、下载原视频或登录来源平台。
- 读取当前使用者已经给出的授权，正常完成其所要求的提取/改写、音视频生成、模板选择、包装和下载。普通界面算力提示本身不增加确认步骤；新增付费重做、异常额度或超出任务范围的动作先处理实际限制。
- 登录、验证码和账号许可交给使用者在页面完成。凭证不进入配置、checkpoint 或报告；新法律协议不能静默接受。
- 声音仅选 `ALLOWED_VOICE_MODELS` 中的实际可用项；形象仅选使用者允许的 `AVATAR_NAMES`，轮换形象后再次核对声音。缺少或不存在的配置不能用作者的个人模型替代。
- 口播参数默认语速 `1.1`、语调 `1.0`、音量 `100`。生成音频后仅在使用者另要求音频文件时下载音频。
- `TOPICS` 恰好 5 个不重复话题。配置 `REQUIRED_TOPIC` 时包含一次该话题并计入总数；未配置时 5 个都按内容选择。话题与正文标题分开，页面、checkpoint 与交付清单使用同一结果。
- 模板按使用者要求自主选最合适的当前可用项，通过卡片/弹窗的真实选中状态核对。配置了 `PERSONA` 才打开人设开关，未配置则关闭。
- 此流程背景音乐选 `无音乐`；包装音量默认 `10`，与口播音量分别核对。无音乐选项导致音量不可用时记录实际状态。使用者要求添加 BGM 时说明输出类型变化并按其明确任务执行。
- 不默认添加额外素材，不修改共享作品名称，不删除已有作品或本机文件。外部发布必须有使用者明确发布请求，完成生成不等于发布授权。
- 点击提交、受理、生成进度、匹配结果与本地文件核验分别记录。`99%`、下载按钮、最新卡片或同一人物都不是完成证据。
- 先定位本次右侧历史卡片并**实际点击视频预览**，再判断中央播放器；未激活的黑屏/`0:00` 不算任务失败。右侧没有本次记录就查本次作品库的包装结果，不能拿口播原片替代最终成片。
- 网页播放故障、正常下载失败分别保留状态。只有本次成片身份和 UI 实际暴露的下载地址均成立且实际使用者已授权下载，才使用本机备用方式；本包不继承任何作者授权。签名 URL 仅作临时输入，不能回显或持久保存。
- 不因选错历史、编辑器清空、播放器未加载或下载故障自动重新生成。保存已受理证据，按对应恢复分支继续。

## 完成交付

1. 最终 MP4 与本次包装结果对应，真实路径和文件完整性通过 `scripts/verify_media.py`。另核对标题/字幕/口播、时长与内容，记录实际听音和画面检查范围；文件存在、AAC 音轨和解码成功都不能证明无背景音乐。
2. 保存本次 checkpoint，再运行 `scripts/recent_sources.py refresh` 更新同一份来源索引。每条完成后更新，批次结束前再次核对；缺少来源 ID 或刷新失败如实记录。
3. 文件与记录保存后关闭本条任务创建且不再需要的标签；保留未完成或使用者明确要求保留的页。按工具支持的方式核对本批创建的页已清理，不关使用者已有标签。
4. 最终给出实际文件链接、标题、5 个话题和完成状态。批量只列非重复且实际完成的条目并连续编号；单条全部被查重跳过时说明未新增成片及原因。未完成、未听音和网页预览不可用等实际边界单独说明。
